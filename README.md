## ✨ Overview

This portfolio was created as part of **Mini Hackathon — Round 2**, where I independently explored **GSAP (GreenSock Animation Platform)** and applied what I learned to a real-world project.

The goal was not simply to add animations, but to understand how **motion, interaction, and visual storytelling** can improve the overall user experience.

The portfolio combines a bold visual design with smooth entrance animations, scroll-based interactions, and interactive sections.

## 🚀 Key Features

### 🎬 GSAP Animations

Smooth and controlled animations implemented using GSAP.

### 📜 ScrollTrigger

Animations are connected to the user's scroll position to create interactive sections.

### 📌 Pin

Selected sections remain fixed while the user continues scrolling, creating a more immersive experience.

### 🔄 Scrub

Animation progress responds directly to the user's scrolling.

### 🎞️ Entrance Animations

Headings, text, cards, and other elements use controlled entrance animations.

### ⏱️ Timelines

Multiple animations are coordinated into sequences using GSAP timelines.

### 🎚️ Easing

Different easing functions are used to make animations feel more natural and polished.

### 🌊 Stagger

Multiple elements are revealed progressively instead of appearing at the same time.

### 📱 Responsive Design

The portfolio is designed to work across desktop, tablet, and mobile screen sizes.

### 🧭 Interactive Navigation

Simple navigation allows users to move between the major sections of the portfolio.

## 🧠 GSAP Concepts Explored

| Concept         | Purpose                                                      |
| --------------- | ------------------------------------------------------------ |
| `gsap.to()`     | Animates an element from its current state to a target state |
| `gsap.from()`   | Animates an element from a defined starting state            |
| `gsap.fromTo()` | Defines both starting and ending states                      |
| Timeline        | Controls multiple animations as a sequence                   |
| Easing          | Controls how an animation moves and feels                    |
| Stagger         | Animates multiple elements with controlled delays            |
| ScrollTrigger   | Connects animations with scrolling                           |
| Pin             | Keeps an element or section fixed during scrolling           |
| Scrub           | Connects animation progress to scroll progress               |

## 🎞️ Animation Philosophy

One of the biggest lessons from this project was:

> **Animation should have a purpose.**

I didn't want to add motion simply because GSAP made it possible.

Instead, I used animation to:

* Guide the user's attention
* Introduce content
* Improve visual hierarchy
* Create storytelling moments
* Make interactions more engaging

The combination of **ScrollTrigger, Pin, and Scrub** was particularly useful for creating sections that respond naturally to user interaction.

## 🧪 Challenges

One of the biggest challenges I faced was understanding **ScrollTrigger**.

Concepts such as:

```text
Trigger
   ↓
Start
   ↓
Scroll Progress
   ↓
Scrub
   ↓
End
   ↓
Pin / Unpin
```

were initially difficult to visualize.

Through experimentation and repeated testing, I gradually understood how changing these values affects the final interaction.

Another challenge was finding the right balance between **visual impact and usability**.

Too little animation could make the experience feel static, while too much animation could make it distracting.
